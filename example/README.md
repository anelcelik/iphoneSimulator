# iphonesim example

A small Cupertino app for trying the simulator: large titles and safe areas
(Places), the keyboard (Notes), what the app sees plus a call to a plugin that
doesn't exist on Linux (Device), and a page with a dark header that turns the
status bar text white (tap a park).

```sh
iphonesim run
```

It also has an `ios/` folder, so you can build the same app for a real iPhone
and compare.
